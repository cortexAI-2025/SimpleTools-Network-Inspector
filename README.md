# SimpleTools Network Inspector — by AIWORKPAY

Application Android gratuite pour diagnostiquer les connexions Wi-Fi, le réseau local et l’accès Internet.

## Statut V1.0.0

- Projet initialisé avec Kotlin, Jetpack Compose, Material 3, Room, DataStore.
- Permissions minimales déclarées.
- CI GitHub Actions configurée (build, tests, lint, artefact APK).
- Architecture MVVM / Repository en cours de construction.
- Modules (Wi-Fi Analyzer, Ping, DNS, LAN Discovery, Security Check, Historique, Exports) à implémenter selon le Mission Codex.

## Principes

- 100 % gratuit, sans publicité, sans compte, sans télémétrie, sans backend.
- Historique local uniquement.
- Diagnostics réels via API Android officielles.

Voir le Mission Codex pour les spécifications complètes.
