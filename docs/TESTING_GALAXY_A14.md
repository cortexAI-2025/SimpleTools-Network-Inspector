# Recette Samsung Galaxy A14 (Android 15)

Checklist manuelle. Les tests automatisés ne remplacent pas la validation sur appareil.

## Scénarios

- [ ] Installation de l’APK debug
- [ ] Démarrage sans crash
- [ ] Wi-Fi connecté : SSID, RSSI, IP, bande visibles
- [ ] Wi-Fi désactivé / mode avion : états corrects
- [ ] Diagnostic automatique
- [ ] DNS Inspector (résolution réelle)
- [ ] Ping Monitor (TCP Connect, statistiques)
- [ ] LAN Discovery (confirmation explicite, plage locale uniquement)
- [ ] Enregistrement et consultation de l’historique
- [ ] Export CSV / JSON / PDF
- [ ] Mode sombre
- [ ] Permissions refusées : messages clairs, pas de crash
- [ ] Redémarrage : persistance de l’historique

## Notes

- Aucune télémétrie.
- Diagnostics réels uniquement.
- Absence de réponse LAN ≠ équipement éteint.
